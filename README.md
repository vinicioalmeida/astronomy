# 🌌 Estudo Independente em Astronomia com Python

## 🧭 Objetivos Gerais

1. Retomar fundamentos de física, com ênfase em gravitação e astrofísica.  
2. Aplicar esses conhecimentos em projetos com dados reais usando Python.  
3. Explorar visualmente o céu com binóculos e ferramentas digitais.  
4. Produzir pequenos relatórios ou notebooks como registro da jornada.  

---

## 🔧 Ferramentas de Apoio

- Python (VS Code)
- Calculadora científica Casio fx-991EX
- Binóculos de boa qualidade
- Biblioteca da UFRN + coleção Resnick/Halliday/Krane (4 volumes)
- Cursos online:
  - [Data Driven Astronomy (Coursera)](https://www.coursera.org/learn/data-driven-astronomy/)
  - [Grok Learning](https://groklearning.com/learn/data-driven-astro/module-0/3/)

## 🔭 Trilhas de Conteúdo

### 📘 Fase 1: Fundamentos Físicos (4 semanas)
- Mecânica Clássica: cinemática, leis de Newton, energia e momentum.
- Gravitação Universal: leis de Kepler, Newton, satélites, órbitas.
- Exercícios com Casio fx-991EX + Python simbólico (SymPy)

### 📗 Fase 2: Astronomia Observacional (4–6 semanas)
- Uso de apps (Stellarium, Sky Map), construção de diário de observações.
- Criação de mapas do céu visível em Natal-RN com `astropy`, `matplotlib`, `pyephem`.

### 📙 Fase 3: Projetos com Dados Reais (6 semanas ou contínuo)
- Uso de catálogos astronômicos (ex: Gaia, SDSS, Exoplanet Archive).
- Projetos em Python:
  - Identificação de exoplanetas via método do trânsito.
  - Visualização de posições estelares em 3D.
  - Simulação de órbitas com `rebound` ou `poliastro`.

### 📒 Fase 4: Projeto Final ou Portfólio
- Escolher uma pergunta científica e responder com dados + visualizações.
  - Exemplo: “Quais exoplanetas próximos teriam visibilidade em Natal nos próximos meses?”

## ✨ Recomendações

- Anote dúvidas e pesquise com calma, sem cobrança de produtividade.
- Registre todo o progresso em um repositório GitHub (diário técnico).
- Combine observação real (binóculo) com simulações computacionais (Python).
- Use o repositório como base de aprendizado, com código, imagens e reflexões.
